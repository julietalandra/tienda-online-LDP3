# Parcial 1 — Laboratorio de Programación 3

Proyecto desarrollado para el primer parcial de la materia Laboratorio de Programación 3, de la Tecnicatura Superior en Desarrollo de Software.

## Tecnologías

- C#
- ASP.NET Core Razor Pages
- HTML, CSS y Bootstrap

## Ejecución

Abrir la solución en Visual Studio y ejecutar el proyecto con **F5** o **Ctrl + F5**.

También se puede ejecutar desde la terminal, dentro de la carpeta que contiene el archivo `.csproj`:

dotnet run
